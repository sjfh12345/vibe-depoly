## 해결한 문제

### 1. GraphQL Mutation 인자 이름 수정
- **문제**: `Unknown argument "input" on field "Mutation.createUser"`
- **원인**: GraphQL API가 `input` 인자를 인식하지 못함
- **해결**: `createUserInput` 인자 이름으로 변경
- **수정 파일**: `src/components/auth-signup/hooks/index.form.hook.tsx`

### 2. API 응답 처리 로직 개선
- **문제**: `_id` 검증 실패로 모달이 표시되지 않음
- **원인**: `onSuccess`에서 `_id` 존재 여부로만 모달 표시 여부 결정
- **해결**: 에러가 없으면 성공으로 간주하여 모달 표시
- **수정 파일**: `src/components/auth-signup/hooks/index.form.hook.tsx`

### 3. 테스트 응답 검증 개선
- **문제**: API 에러를 명확히 확인하지 못함
- **해결**: 테스트에서 API 에러를 명시적으로 확인하도록 수정
- **수정 파일**: `tests/components/auth-signup/index.form.hook.spec.ts`
